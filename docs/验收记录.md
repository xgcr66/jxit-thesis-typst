# 模板验收记录

核验时间：2026年9月27日至28日。核验平台：Windows，Microsoft Word 本机 COM 排版，Typst 0.15.1，python-docx 1.2.0。

## 实际执行

- `python scripts/build.py --update-fields`：成功生成 PDF 和可编辑 DOCX。
- `powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1 -UpdateFields`：已通过用户入口实际导出。
- `python -m unittest discover -s tests -v`：16项测试通过，0项失败。
- Microsoft Word：实际打开最终DOCX，更新目录并导出检查用PDF，共14页。
- Typst PDF：编译成功，共14页。

已检查封面校徽、声明、摘要、三级目录、章标题、图表、页码及参考文献、附录、致谢。修复了图片被固定行距裁剪、标题装饰线、目录域结束段引起的空白页、Word内置目录样式映射，以及参考文献标题对齐问题。

通用DOCX渲染工具因本机未安装LibreOffice而无法运行，改用实际Microsoft Word导出PDF，再逐页渲染检查。本记录不声称已验证LibreOffice、WPS、macOS或Linux显示一致性。

## 数据与文件

正文是模板填写提示，未填入个人账号、真实论文、密钥或签名。输出Word已清除本机最后修改者字段。项目提供校徽及自有流程图，未分发商业字体和学校规范原文件。

页眉页脚2.8 cm与有效正文边界3.5 cm的处理经使用者确认，具体公式和依据见《格式依据》。正式提交仍需核对学院最新要求；模板中的待填写项必须替换，示例参考文献数量不满足正式论文数量要求。
