# 双格式导出说明

## 内容流

`thesis.typ → Typst 解析 → 结构化元数据 → Word 生成器`

同时 `main.typ + lib/layout.typ → Typst PDF`。Word 并非从 PDF 图片转换而来，文字与表格可直接编辑。模板不依赖在线API。

支持：封面、声明、摘要、关键词、三级标题、普通段落、上标数字引用、PNG/JPEG图片、表格、短代码块、分页、参考文献、附录和致谢。

暂不支持：任意Typst宏到Word的通用转换、自动GB/T参考文献解析、复杂公式转换、脚注/尾注语义块、Word编辑回写Typst。需要这些功能时可扩展 lib/model.typ 与两个渲染器；禁止将未支持内容当作已转换成功。

## 使用建议

以 thesis.typ 为唯一内容来源，在导出文件中做排版检查。导出器验证内容类型、引用范围、标题层级、图片是否位于项目内及表格列数，错误会停止而不是悄悄漏内容。

图题与表题在重新导出时按章统一计算，Word中直接新增或删除图表后应手工更新编号或回源重建。Word目录是原生域，可右键更新整个目录。Windows安装了Word时，`-UpdateFields`调用独立隐藏Word实例更新，完成后关闭该实例。若Word被占用或COM不可用，DOCX仍已生成，程序明确提示目录需手工更新。

`build`可能包含个人论文，默认被Git忽略。examples只放模板自有演示稿，公开仓库不要用个人毕业论文覆盖examples。

## 版本与字体

验证版本为Typst 0.15.1、python-docx 1.2.0。安装脚本只支持Windows x64自动下载；其他平台请从Typst官方安装渠道安装同版本并设置PATH。

同一内容在PDF与Word中的分页允许不同，二者分别生成目录。字体必须本机安装且获得使用许可；项目不再分发字体。Typst官网在线编辑可以打开main.typ生成PDF，但须提供合规字体并重新验收，网站自身没有运行本项目Python Word导出器的功能。
